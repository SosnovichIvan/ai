# Правила проекта

- Все существенные изменения проходят OpenSpec SDD: current spec → change artifacts → проверка → archive.
- Перед реализацией прочитайте `openspec/specs/`, активный change и соответствующие материалы из `ai/`.
- `ai/` — единственный редактируемый каталог правил, skills и профилей установки. Не изменяйте сгенерированные копии в целевых проектах вручную.
- Установщик обязан сначала показать plan/diff, нормализовать и проверить путь, не выходить за его пределы и создавать резервные копии заменяемых файлов.
- Установка не должна перезаписывать пользовательские инструкции без явного режима `replace`; стандартное поведение — `merge` либо остановка при конфликте.
- Не читать, не копировать и не логировать секреты, `.env`, токены, cookies или приватные ключи.
- Для UI изменение не начинается без согласованного Figma URL с `node-id`, записанного в `design-approval.md` активного change.
- Все пользовательские сообщения и OpenSpec-артефакты пишутся по-русски; имена файлов, команды и ключевые слова OpenSpec остаются на английском.
