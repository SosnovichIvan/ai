# Правила поставки

Сборка должна быть воспроизводимой: зафиксированные зависимости, явная версия,
минимальный runtime-образ/бинарник и проверка запуска без developer toolchain.
Конфигурация окружения отделена от образа; секреты не входят в layers,
манифесты, example-файлы и build logs.

Каждое окружение имеет проверяемый health/readiness, ограничения ресурсов,
безопасные network boundaries и rollback. Deploy выполняется через утверждённый
pipeline, а не ручной изменением production. Перед release проверьте миграции,
совместимость конфигурации, наблюдаемость и путь восстановления.
