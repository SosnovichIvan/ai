# Правила установки конфигурации

- Целевой путь должен существовать, быть каталогом и быть доступен для записи.
- Все вычисленные пути должны оставаться внутри целевого каталога после
  нормализации и разрешения символьных ссылок.
- До записи обязательно рассчитывать и показывать plan.
- Повторный запуск с одинаковой версией должен быть идемпотентным.
- Неизвестные или изменённые пользователем файлы считаются конфликтом: по
  умолчанию они не перезаписываются.
- Перед заменой управляемого файла создать timestamped backup в
  `.agent-config/backups/` целевого проекта.
- Manifest хранит только относительные пути, версии, хэши и timestamp; секреты
  и содержимое пользовательских файлов в него не попадают.
