# Каталог конфигурации агентов

`ai/` — канонический источник навыков, правил и профилей, которые установщик
публикует в выбранный проект. Целевые каталоги являются производными и не должны
редактироваться вручную.

## Состав

- `rules/` — общие обязательные правила.
- `skills/` — локальные Codex skills в формате `SKILL.md`.
- `profiles/` — декларации наборов для установки.
- `templates/` — будущие версионируемые шаблоны формирования задач.
- `catalog.yaml` — единая карта файлов, их версии и целевых путей.
- `source-analysis.md` — реестр проверенных исходных репозиториев и решения о
  переносимости их практик.

## Принцип установки

1. Установщик читает только этот каталог и `catalog.yaml`.
2. Рассчитывает plan: новые файлы, безопасные обновления и конфликты.
3. После подтверждения создаёт backup заменяемых файлов внутри цели.
4. Записывает manifest с версией каталога и хэшами установленных файлов.

Шаблоны задач также будут храниться только в `ai/`: у каждого появятся
стабильный идентификатор, версия, schema параметров и содержимое. Сформированная
задача будет хранить ссылку на использованную версию шаблона, поэтому результат
останется воспроизводимым после обновления каталога.

Это позволяет повторно запускать установку без дублирования, а обновления —
сравнивать с предыдущим manifest.
