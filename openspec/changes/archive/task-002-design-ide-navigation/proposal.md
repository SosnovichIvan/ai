## Why

Пользовательский сценарий требует постоянной IDE-подобной структуры, в которой
настройка окружения и работа над задачами остаются отдельными понятными режимами.

## What Changes

- Проектируется desktop UI в Figma file `KYcd8hPuczEIpqK9dbG5D7`.
- Создаётся постоянная левая навигация с двумя верхнеуровневыми разделами.
- Описываются первые рабочие экраны обоих разделов.
- Для работы с задачами создаётся отдельная Figma Page с редактором,
  templates и пользовательскими блоками задач.

## Scope

Figma wireframe/high-fidelity design для desktop-first приложения, состояния
навигации и информационная архитектура двух разделов.

## Non-Goals

- Реализация desktop-приложения, installation core или CLI.
- Утверждение конкретных цветов/визуальной системы до изучения Figma file.
- Детализация формата task templates и локального хранилища.

## Impacted Boundaries

- **Code/files:** Figma file, OpenSpec change.
- **Target projects:** отсутствуют.
- **Security:** дизайн показывает preview и конфликт как обязательные этапы, но не раскрывает секреты.
- **Compatibility/rollback:** Figma-версия изолирована в отдельном top-level frame и может быть пересмотрена без изменения реализации.
