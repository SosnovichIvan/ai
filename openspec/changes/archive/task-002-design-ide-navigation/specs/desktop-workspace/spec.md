## ADDED Requirements

### Requirement: IDE-like primary navigation

Desktop интерфейс SHALL отображать блок `AI Works` в левой части окна с двумя
верхнеуровневыми рабочими областями: «Установка окружения» и «Задачи и шаблоны».
Отдельный icon rail SHALL NOT отображаться.

#### Scenario: Переключение рабочей области

- **WHEN** пользователь выбирает пункт в левой панели
- **THEN** центральная рабочая область показывает содержимое выбранного раздела, а `AI Works` отображает его как активный

### Requirement: Environment installation workspace

Раздел «Установка окружения» SHALL показывать выбор целевой папки, профиль,
preview операций и доступность apply только после успешного preview.
Основные действия SHALL находиться справа в строке заголовка раздела.

#### Scenario: Открытие установки без выбранной папки

- **WHEN** пользователь впервые открывает раздел «Установка окружения»
- **THEN** интерфейс предлагает выбрать папку и показывает apply как недоступное действие

#### Scenario: Выбор папки через системный диалог

- **WHEN** пользователь нажимает `Выбрать папку`
- **THEN** приложение открывает нативный dialog ОС, а после успешного выбора показывает read-only путь, `Изменить папку` и активное действие apply

### Requirement: Observable profile installation

Во время установки профиль SHALL отображать список стадий, текущую операцию,
процент завершения и итоговый статус без раскрытия содержимого secrets.

#### Scenario: Установка standard profile

- **WHEN** пользователь запускает apply для проверенной папки
- **THEN** интерфейс показывает прогресс подготовки backup, записи rules, записи skills и обновления manifest до финального результата

#### Scenario: Конфликт управляемого файла

- **WHEN** preview или установка обнаруживает локально изменённый управляемый файл
- **THEN** интерфейс показывает conflict, сохраняет пользовательский файл без перезаписи и предлагает безопасное следующее действие

### Requirement: Rules and skills text review

Рабочая область SHALL предоставлять локальные вкладки `Skills` и `Rules` с
текстовым просмотром, редактированием и явным сохранением правок.

#### Scenario: Изменение skill

- **WHEN** пользователь редактирует текст skill
- **THEN** интерфейс помечает документ как несохранённый и сохраняет его только после явного действия пользователя

### Requirement: Tasks and templates workspace

Раздел «Задачи и шаблоны» SHALL показывать task list, template list и действие
создания задачи, сохраняя понятное empty state при отсутствии локальных данных.
Действие создания задачи SHALL находиться справа в строке заголовка раздела.

#### Scenario: Открытие пустого task workspace

- **WHEN** в локальном хранилище ещё нет задач и templates
- **THEN** интерфейс объясняет отсутствие данных и предлагает создать первую задачу
