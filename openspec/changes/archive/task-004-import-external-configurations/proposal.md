## Why

Текущий редактор показывает только встроенный минимальный профиль и при быстром
переходе между `Skills` и `Rules` мог обращаться к несуществующему выбранному
элементу. Пользователю также нужен контролируемый способ анализировать папки с
существующими правилами и skills, включая ранее исследованные репозитории, и
решать, расширять ли ими локальный набор или заменять его.

## What Changes

- Устраняется сбой при переключении между вкладками `Skills` и `Rules`.
- Добавляется сценарий «Анализировать папку» с нативным выбором директории.
- Добавляется безопасный анализ допустимых rules и skills с исключением
  секретов и технических каталогов.
- Перед импортом показываются найденные элементы, конфликты и preview изменений.
- Пользователь явно выбирает режим `Добавить` или `Заменить`; замена требует
  дополнительного подтверждения и резервной копии управляемого набора.
- Runtime-каталог приложения становится редактируемой локальной копией,
  первоначально заполненной из версионируемого `ai/`.

## From / To

- **From:** правила и skills в приложении заданы статическим встроенным списком;
  внешние наборы нельзя безопасно просмотреть и подключить.
- **To:** приложение отображает фактический активный каталог, позволяет
  безопасно анализировать выбранную папку и применяет только явно выбранный
  пользователем режим импорта после preview.

## Scope

- Environment UI и утверждённый Figma-сценарий импорта.
- Rust IPC для folder picker, анализа, preview и commit импорта.
- Версионируемый runtime-каталог, его seed, backup и manifest происхождения.
- Обновление текущих спецификаций после проверки и archive change.

## Non-Goals

- Сканирование всего компьютера, фоновые наблюдатели каталогов и сетевой импорт.
- Выполнение кода, shell-команд или инструкций из найденных файлов.
- Чтение, показ, копирование или логирование секретов.
- Автоматическое слияние конфликтующего содержания без выбора пользователя.

## Version

- **Previous:** v1.0.0 MVP.
- **Target:** v1.1.0.
- **Level:** MINOR.
- **Rationale:** добавляется обратимо управляемая возможность импорта локальной
  конфигурации без изменения default-поведения установки.

## Capabilities

### New Capabilities

- `external-configuration-import`: анализ и контролируемое подключение
  локальных rules и skills.

### Modified Capabilities

- `configuration-catalog`: runtime-копия каталога заменяет статический список
  после явного import commit.
- `desktop-agent-config`: Environment UI получает сценарий external import.

## Impacted Boundaries

- **Services/code:** Rust filesystem scanner, typed IPC, React environment UI.
- **Data/migrations:** app-data runtime catalog, manifest происхождения и
  timestamped backup перед replace.
- **Security/privileges:** filesystem scope ограничен единственной папкой,
  выбранной в системном диалоге; запрещённые файлы даже не читаются.
- **Compatibility/rollout:** bundled `ai/` остаётся seed и source of truth в
  репозитории; действующие профили продолжают работать до commit импорта.
