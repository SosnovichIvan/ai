## Причина отмены

Продукт меняет модель поставки: вместо установки desktop-бинарников становится
web-приложением с учётными записями. Подписание macOS, Windows и Linux
артефактов, их каталог и публикация больше не входят в целевой продукт.

Работа по задаче не начиналась: secrets, сертификаты и release не создавались.
Задачу заменяет `task-013-web-application-authentication`.
