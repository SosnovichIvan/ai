## Purpose

Установка конфигурации безопасно применяет профиль к явно выбранной локальной
директории, не повреждая пользовательские данные и сохраняя возможность отката.

## Requirements

### Requirement: Validated installation target

Система SHALL принимать только существующий доступный для записи каталог и
SHALL отклонять путь, если рассчитанный destination выходит за его пределы.

#### Scenario: Некорректная директория

- **WHEN** пользователь указывает несуществующий файл или недоступный каталог
- **THEN** установка не создаёт и не изменяет файлы и показывает причину отказа

### Requirement: Preview before mutation

Система SHALL показывать список create, unchanged, update и conflict до любой
записи в целевой проект.

#### Scenario: Конфликт управляемого файла

- **WHEN** manifest указывает, что управляемый файл изменён пользователем
- **THEN** preview содержит conflict и стандартная установка не перезаписывает этот файл

### Requirement: Recoverable write

Система SHALL создавать backup перед заменой управляемого файла и SHALL
обновлять manifest только после успешного завершения всей операции.

#### Scenario: Ошибка во время записи

- **WHEN** запись любого файла завершается ошибкой
- **THEN** система сообщает о неуспехе и использует backup для восстановления уже заменённых файлов
